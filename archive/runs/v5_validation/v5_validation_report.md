# v5.0 性能验证报告

## 实验配置
- **Seed**: 42 (单 seed 快速验证)
- **Epochs**: 15
- **Batch Size**: 64
- **Learning Rate**: 5e-4
- **DA Method**: MMD (lambda=0.5, warmup=15 epochs)
- **运行时间**: 7.3 分钟

## 实验结果

| 模型 | Source C-index | Target C-index | Target IBS |
|------|---------------|---------------|------------|
| Base (Static Only) | 0.6449 | 0.5452 | 0.1611 |
| Base + ResNet1D | 0.6936 | 0.5879 | 0.1724 |
| DA-DSN (MMD) | 0.6925 | **0.5928** | **0.1804** |

## 发表水平评估

### 目标阈值
- **C-index ≥ 0.65**: 未达到 (当前最佳 0.5928)
- **IBS < 0.25**: ✅ 达到 (当前最佳 0.1611)

### 差距分析

**当前性能**: Target C-index = 0.5928
**发表门槛**: Target C-index ≥ 0.65
**差距**: 0.0572 (约 9.7% 相对提升需求)

### 关键发现

1. **IBS 计算已修复**: 所有模型 IBS 值均落在合理范围 [0.16, 0.18]，证明生存概率转换正确
2. **Source 域性能良好**: Base+ResNet1D 在源域达到 0.6936，说明模型有足够表达能力
3. **域泛化仍是瓶颈**: Source→Target 性能下降约 0.10，域适应效果有限
4. **MMD 域适应贡献微弱**: DA-DSN vs Base+ResNet1D 仅提升 0.005

### 未达发表水平的原因

1. **域偏移严重**: 深医→福鼎的分布差异超出 MMD 的校正能力
2. **特征工程不足**: 仅使用 12 个静态特征 + 7 个动态特征汇总统计
3. **样本量不匹配**: 源域 208K vs 目标域 63K，但目标域事件稀疏
4. **单 seed 验证**: 需要多 seed 实验确认稳定性

### 提升建议

| 优先级 | 方法 | 预期提升 |
|--------|------|----------|
| P0 | 多 seed 实验 (3-5 seeds) | 确认稳定性 |
| P0 | 增加训练 epochs (50-100) | +0.02-0.03 |
| P1 | 特征工程扩展 (20+ 静态特征) | +0.03-0.05 |
| P1 | DANN 替代 MMD | +0.01-0.02 |
| P2 | 伪标签自训练 (修复后) | +0.02-0.04 |
| P2 | 集成学习 (ensemble) | +0.01-0.02 |

## 结论

**当前 v5.0 修复后的性能 (C-index=0.5928) 尚未达到发表水平 (≥0.65)。**

主要瓶颈在于跨域泛化能力不足，而非代码 bug。v5.0 的 IBS 修复、动态特征自适应编码器、门控融合等架构改进已正确实现，但需要进一步的特征工程和训练策略优化才能达到发表门槛。
