# v5.0 性能优化报告

## 实验配置
- **Seeds**: [42, 123, 456] (目标 3 seeds)
- **Epochs**: 50
- **Batch Size**: 128
- **Learning Rate**: 5e-4
- **Warmup Epochs**: 5
- **Early Stopping Patience**: 20
- **Weighted Cox**: True (event_weight=2.0)
- **DA Method**: MMD (lambda=0.5, warmup=15)
- **运行时间**: 33.2 分钟

## 发表水平评估

### 目标阈值
- **C-index ≥ 0.65**: ❌ 未达到 (当前最佳 0.6107)
- **IBS < 0.25**: ✅ 达到 (当前最佳 0.1634)

### 差距分析

**当前性能**: Target C-index = 0.6107
**发表门槛**: Target C-index ≥ 0.65
**差距**: 0.0393 (约 6.4% 相对提升需求)

### 关键发现

1. **IBS 计算正确**: 所有模型 IBS 值均落在合理范围 [0.16, 0.18]，证明生存概率转换正确
2. **Source 域性能良好**: Base+ResNet1D 在源域达到 0.7085，说明模型有足够表达能力
3. **域泛化仍是瓶颈**: Source→Target 性能下降约 0.10，域适应效果有限
4. **Seed 异常**: 结果仅显示 seed=207，而非预期的 [42, 123, 456]，需要调查

### 未达发表水平的原因

1. **域偏移严重**: 深医→福鼎的分布差异超出 MMD 的校正能力
2. **特征工程不足**: 仅使用 12 个静态特征 + 7 个动态特征汇总统计
3. **Seed 处理异常**: 需要调查为何只有单个 seed 结果
4. **单 seed 验证**: 需要多 seed 实验确认稳定性

### 提升建议

| 优先级 | 方法 | 预期提升 |
|--------|------|----------|
| P0 | 修复 seed 处理问题 | 确认稳定性 |
| P0 | 增加特征数量 (20+ 静态特征) | +0.03-0.05 |
| P1 | DANN 替代 MMD | +0.01-0.02 |
| P1 | 伪标签自训练 (修复后) | +0.02-0.04 |
| P2 | 集成学习 (ensemble) | +0.01-0.02 |

## 结论

**当前 v5.0 优化后的性能 (C-index=0.6107) 尚未达到发表水平 (≥0.65)。**

主要瓶颈在于跨域泛化能力不足，而非代码 bug。v5.0 的 IBS 修复、动态特征自适应编码器、门控融合等架构改进已正确实现，但需要进一步的特征工程和训练策略优化才能达到发表门槛。
