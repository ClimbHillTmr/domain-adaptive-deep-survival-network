## 数据构建增强
- 生成 minutes_from_start：将 `透中数据记录时间节点` 统一为 datetime 并计算相对起始分钟数组与 `duration_minutes`。
- 事件与标签：
  - 以 `透析中收缩压` 和规则 `(fp - p >= 30) 或 p <= 90` 计算事件分钟 `et_min`（首次满足），生成 `events`（0/1）。
  - 两套阶段标签：`stage_30_60_120` 与 `stage_30_90_120`；保留 `降幅/涨幅` 比值/差值与区间列。
- 序列与邻域特征（SBP/MAP/HR/UF）：
  - 序列统计：mean/std/min/max/slope；滚动STD均值（w=3/5/7）、短窗均值斜率（w=3/5/7）、最小值位置比例；UF一/二阶差分绝对均值。
  - 事件邻域：在 `et_min` 附近作 pre/post（w=3/5/7/9）均值/STD/斜率、pre-post 差分、极值至事件相对位置；`et_min=None` 时置0并标注。
- 透前与历史聚合：
  - 透前静态：SBP/DBP/MAP、体重/干体重、透析龄_天数、实际时长、液温/电导率/钙浓度、呼吸频率/体温（存在即接入）。
  - 历史均值与比率：按患者ID+透析日期 `groupby+expanding` 生成 `历史平均<列>` 与 `history_*`（HBP、LBP_times_k 及其 rate）；首次记录设0。
- 一致性与QA：
  - 安全解析列表（替代 `eval` 为 `ast.literal_eval`），长度一致性校验→写入 `removed_inconsistent_rows.csv`；极值裁剪（q5/q95）；输出 `schema.json` 与 QA日志。
- 导出：`深医_enhanced_final.csv`、`福鼎_enhanced_final.csv`。

## Loader对接
- 读取增强版CSV：
  - 使用 `et_min/透析开始/结束/duration_minutes` 构造 `durations/events` 与阶段标签（选择边界列）。
  - 启用序列/邻域/透前/历史特征，打包 `X` 或 `X_seq/X_static`（Transformer 静态包含邻域集）。

## Runner联动与校准阈值
- 两路径（LightGBM/Transformer）：
  - 分阶段等距校准（isotonic）→两路阈值优化：按类 F-β（温和 betas）与分布约束（训练分布平滑占比，早期最小占比≥1%）。
  - 温和阈值应用：未发生最低阈值≥0.22、早期阈值 0.05–0.10、低置信门槛≈0.25、优先级仅冲突时触发；写出 `thresholds*.json`、`metrics_thresholded.json`、`external_metrics_thresholded.json`；绘制 `calibration_*`。
  - 外部先验修正：对 `proba_ext` 用训练占比平滑迁移修正并归一化，再行校准与阈值优化。
- 生存一致性：拟合 CoxPH 输出 `coefficients.csv`（HR/CI/p值）；将 S(t) 映射阶段软标签并生成 `stage_soft_vs_pred.csv` 比对分类概率。

## 复跑与输出
- 两套边界：主 `30-90-120`、对照 `30-75-120`；两条路径：LightGBM 与 Transformer。
- 输出目录包含：
  - `internal/external_metrics.json`、`metrics_thresholded.json`、`external_metrics_thresholded.json`
  - `thresholds*.json`、`calibration_*`、`confusion_matrix.csv`
  - `coefficients.csv`、`stage_soft_vs_pred.csv`
  - 扩展指标与图表：时间依赖AUC、C-index/IBS、可靠性曲线、分阶段PR/ROC、SHAP/PDP、HR/CI森林图。

## 验收标准
- 外部早期召回≥1%，brier 不恶化；校准曲线贴近对角线；中/晚期召回稳定；HR/CI 显著性合理、软标签一致性具解释性。
