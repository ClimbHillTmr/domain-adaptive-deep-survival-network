## 执行概览
- 构建增强版数据（minutes_from_start、et_min/events、两套阶段标签、序列与事件邻域特征、透前与历史聚合），输出深医/福鼎增强版最终CSV与QA日志和schema。
- 对接 Loader 与 Runner，启用新增特征，接入分阶段校准+分布约束阈值与外部先验修正，落地 CoxPH 生存一致性输出。
- 复跑两条路径（LightGBM/Transformer）与两套边界（30-90-120、30-75-120），提交完整报告与论文图表（时间依赖AUC、C-index/IBS、可靠性曲线、分阶段PR/ROC、SHAP/PDP、HR/CI森林图）。

## 详细步骤
1) 数据构建增强（data_preprocessing）
- 解析与规范：替换不安全解析为安全管线；统一时间为 datetime 并生成 `minutes_from_start` 与 `duration_minutes`；列表与时间节点长度一致性校验与 QA 日志；极值裁剪（q5/q95）。
- 事件与标签：计算 `et_min`（距起始分钟）、`events`（0/1）；生成 `stage_30_60_120` 与 `stage_30_90_120` 两套阶段列；保留 `降幅/涨幅` 比值/差值及区间。
- 特征追加：
  - 序列统计（mean/std/min/max/slope、滚动STD均值 w=3/5/7、短窗斜率 w=3/5/7、最小值位置比例、UF 一/二阶差分绝对均值）。
  - 事件邻域（w=3/5/7/9）：pre/post 均值/STD/斜率、pre/post 差分、极值至事件相对位置、邻域波动；`et_min=None` 时置 0 并标注。
  - 透前/治疗静态（SBP/DBP/MAP、体重/干体重、透析龄_天数、实际时长、液温/电导率/钙浓度、呼吸频率/体温等）。
  - 历史聚合（groupby+expanding）：`历史平均<列>` 与 `history_*`（HBP、LBP_times_k 及 rate），首次记录设 0。
- 导出：`深医_enhanced_final.csv`、`福鼎_enhanced_final.csv`（附 `schema.json` 与 QA 日志）。

2) Loader 对接（src/data/loader.py）
- 启用新增特征；用 `et_min/透析开始/结束/duration_minutes` 构造 `durations/events` 与阶段标签（选择边界列）；
- 打包 `X` 或 `X_seq/X_static`（Transformer 静态包含邻域与历史特征）。

3) Runner 联动（src/training/runner.py）
- 分阶段等距校准（isotonic）后执行两路阈值优化：按类 F-β（温和 betas）与分布约束（训练分布平滑占比，早期最小占比≥1%）。
- 温和阈值应用：未发生最低阈值≥0.22、早期阈值 0.05–0.10、低置信门槛≈0.25、优先级仅在多类冲突时触发；写出 `thresholds*.json`、`metrics_thresholded.json`、`external_metrics_thresholded.json`；绘制 `calibration_*`。
- 外部先验修正：对 `proba_ext` 用训练占比平滑迁移修正并归一化，再行校准与阈值优化。
- 生存一致性：拟合 CoxPH 输出 `coefficients.csv`（HR/CI/p 值），将 S(t) 映射阶段软标签并生成 `stage_soft_vs_pred.csv`。

4) Transformer 修复与增强
- `TorchStageWrapper.predict_proba` 做 softmax 后归一与去 NaN/裁剪并按行归一，长度与轴对齐；
- 增加训练轮次/隐藏维度/多头与轻度类别权重；在 Runner 外部评估中接入同样的校准与阈值联动与先验修正。

5) 复跑与输出
- 两路径：LightGBM/Transformer；两边界：主 `30-90-120`、对照 `30-75-120`；
- 输出：`internal/external_metrics.json`、`metrics_thresholded.json`、`external_metrics_thresholded.json`、`thresholds*.json`、`calibration_*`、`confusion_matrix.csv`、`coefficients.csv`、`stage_soft_vs_pred.csv`、扩展指标与图表（时间依赖AUC、C-index/IBS、可靠性曲线、分阶段PR/ROC、SHAP/PDP、HR/CI森林图）。

## 验收标准
- 外部早期召回≥1%，brier 不恶化；校准曲线贴近对角线；中/晚期召回稳定；HR/CI 显著性合理、软标签一致性具解释性。
