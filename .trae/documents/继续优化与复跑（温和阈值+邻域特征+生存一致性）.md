## 目标
- 提升外部早期召回并保持中/晚期稳定，避免阈值化坍缩，确保 brier 不恶化；补齐论文所需指标与解释性输出。

## 待实现优化
1. 数据与特征增强（Loader）
- 事件邻域特征：在 SBP/MAP/HR/UF 上加入 w∈{3,5,7,9} 的 pre/post 均值/STD/斜率、pre/post 差分、极值至事件相对位置、UF 邻域二阶波动；缺列安全兜底为 0。
- 透前/历史特征：完整接入透析液温度/电导率/呼吸频率以及历史均值/比例/次数（如 history_HBP_rate、history_LBP_times_*），若最终 CSV 缺失则保留占位不报错。

2. 校准与阈值联动（Runner）
- 分阶段等距校准（isotonic）后执行两路阈值优化：按类 F-β（温和 betas）与分布约束（目标为训练分布平滑占比，早期设最小占比≥1%）。
- 温和阈值应用：未发生类最低阈值≥0.22、早期阈值 0.05–0.10、低置信门槛≈0.25、优先级仅在多类冲突时触发；写出 external_metrics_thresholded.json。
- 先验修正（可选）：对外部 proba 用训练占比进行迁移修正并归一化，再做校准与阈值优化。

3. 生存一致性（Cox）
- 用静态特征拟合 CoxPH（内部/外部），输出 `coefficients.csv`（HR/CI/p 值），将 S(t) 映射为阶段软标签并生成 `stage_soft_vs_pred.csv` 比对分类概率一致性。

4. 模型训练增强
- LightGBM：保持增强超参与早期轻度 sample_weight；Transformer CPU 小模型继续作为第二路径对照。

## 复跑与输出
- 两条路径：LightGBM 与 Transformer；两套边界：主 `30-90-120`，对照 `30-75-120`。
- 输出：`internal/external_metrics.json`、`metrics_thresholded.json`、`external_metrics_thresholded.json`、`thresholds*.json`、`calibration_*` 图、`confusion_matrix.csv`、`coefficients.csv`、`stage_soft_vs_pred.csv`、扩展指标（时间依赖AUC、C-index/IBS、可靠性曲线）。

## 验收标准
- 外部早期召回提升至≥1%，brier 不恶化；校准曲线更贴近对角线；中/晚期召回稳定；HR/CI 显著性合理、软标签一致性具备可解释性。

## 执行顺序（一次性）
1) 扩展 Loader 特征 → 2) 接入 Runner 校准+阈值联动与先验修正 → 3) 生存辅助输出 → 4) 复跑两路径两边界 → 5) 汇总报告与论文指标/图表。
