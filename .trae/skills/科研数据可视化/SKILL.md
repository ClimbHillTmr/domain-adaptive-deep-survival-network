# 科研数据可视化

## 目标

把研究问题转化为可审计的图，而不是把所有指标堆进一张图。默认使用 Python 的 Matplotlib 和 Seaborn；交互式探索可用 Plotly。只有用户提供可访问环境和明确需求时才声称使用 Tableau 或 Power BI。

开始本仓库的正式绘图前读取 [CLAUDE.md](file:///home/cht/Works/domain-adaptive-deep-survival-network/CLAUDE.md)，确认数据角色、统计单位、主估计量和允许表述。

## 选图规则

| 研究问题 | 首选图 | 禁止误用 |
|---|---|---|
| 随时间或训练轮次变化 | 折线图、带状置信区间图 | 无序类别用折线连接 |
| 模型或组间比较 | 点区间图、分组柱状图 | 只有均值没有不确定性 |
| 构成比例 | 100%堆叠条形图；类别很少时可用饼图 | 类别过多、3D饼图 |
| 两连续变量关系 | 散点图、回归或平滑曲线 | 用相关性暗示因果 |
| 二维矩阵或相关结构 | 热力图 | 不显示色标或聚类规则 |
| 网络或关系结构 | 网络图、Sankey或弦图 | 无边权、节点定义或布局说明 |
| 预测判别 | ROC与PR曲线 | 低患病率终点只报ROC |
| 校准 | calibration curve、截距/斜率森林图 | 把判别力当校准 |
| 模型差值 | paired delta forest/interval plot | 分别画两个AUC而不画配对差 |
| 多模型多终点 | 分面图、多面板图 | 双Y轴制造视觉关系 |

## 强制工作流

### 1. 定义图的结论

绘图前写一句：

```text
该图要让读者判断：[明确问题]
```

若无法写出这句话，先停止绘图。

### 2. 核查数据

- 明确一行代表患者、session、模型、种子还是bootstrap replicate。
- 医学推断优先患者级不确定性；不得把session当独立重复。
- 检查缺失、重复、异常值、类别排序和单位。
- 不生成模拟数据替代缺失结果。需要演示时必须明确标记“模拟数据”。

### 3. 视觉编码

- 使用色盲友好配色，默认 Okabe-Ito 或同等方案。
- 同一模型、端点和中心在所有图中保持颜色与符号一致。
- 位置优先于面积和角度，因此精确比较优先点区间图而非饼图。
- 显示原始数据或分布时，叠加透明散点、箱线或小提琴；大样本使用hexbin或密度图。
- 网络图必须说明节点、边、权重、过滤阈值和布局算法。

### 4. 统计标注

- 明确误差线是SD、SE、95% CI还是bootstrap percentile CI。
- 多模型比较优先显示效应差和CI，不机械添加星号。
- p值需注明双侧/单侧、聚类单位和多重校正方法。
- PR-AUC同时标记端点患病率基线。
- 选择性对齐图必须同时展示 G 和 C，防止把“少损害”误写成“有增益”。

### 5. 导出与质检

用户规则要求图片默认导出PDF，不在界面直接渲染。推荐同时保留：

- PDF：矢量主稿
- SVG：后期编辑
- PNG或TIFF：期刊要求的高分辨率位图
- CSV：图中全部数值

最低质量要求：

- 最终版面尺寸下字体可读
- 坐标单位完整
- 图例不遮挡数据
- 灰度打印仍可区分
- 色盲模拟可辨
- 面板字母、图注和正文引用一致
- PDF字体嵌入，线宽和透明度不过细

## 本项目推荐图组

1. 队列和患者级拆分流程图。
2. 两中心终点患病率与关键特征分布图。
3. 八个核心模型在IDH/IH上的ROC AUC与PR-AUC点区间图。
4. D1-G、D2-G、D1-C、D2-C患者配对差值森林图。
5. 五个种子差值图，用于识别单种子依赖。
6. 19个exact-size随机分区联合统计量分布与临床分区位置。
7. 校准前后曲线及截距/斜率比较。
8. 信息组source-to-target transportability矩阵或热力图。
9. 文献或特征关系明确时使用网络图，不为装饰创建网络。

## 工具能力

- Matplotlib：版式、坐标、注释、矢量导出和期刊尺寸的精细控制。
- Seaborn：分布图、分类比较、热力图和统计默认样式。
- Plotly：交互式探索和HTML报告，不替代论文静态主图。
- NetworkX：特征、文献、作者或引用网络的计算与布局。
- Tableau/Power BI：仅在用户提供环境、数据连接和交付格式时设计仪表板；否则提供数据模型和图表规范，不伪称已执行。

## 输出格式

每次输出包括：

1. 图的研究问题
2. 数据字段与统计单位
3. 图形方案和选择理由
4. 生成代码或工具步骤
5. PDF及源数据路径
6. 可视化审计结果
7. 图注草稿
