# 投稿前整改计划

## 研究定位

当前研究应定位为双中心回顾性预测与目标中心标注辅助更新研究，而不是严格无监督域适应研究。

推荐主问题：

> 在 Shenyi 与 Fuding 两个血透中心存在明显血流动力学和事件时间分布差异时，基于 Shenyi 训练的生存预测模型能否通过少量 Fuding 标注样本进行本地更新，并在未参与更新和模型选择的 Fuding held-out 患者中改善 IDH 发生时间风险预测？

因此，论文主线应为：

1. 描述两中心 cross-center shift。
2. 建立 Shenyi source-only 生存预测基线。
3. 使用 Fuding adaptation subset 的标注结局进行 target-center updating。
4. 在 patient-level held-out Fuding test subset 上评估。
5. 同时报告 discrimination、calibration、Brier score 和 decision curve analysis。
6. 将结论限制在风险分层和本地更新有效性，不声称无需目标标签即可泛化。

## 已纳入代码层面的默认约束

1. `conf/config.yaml` 默认使用 `data.split_strategy: "patient"`。
2. `src/data/dataset.py` 在 Fuding 目标域按 `患者id` 做 patient-level adaptation/validation/test 切分。
3. 若要求 patient-level split 但最终 CSV 缺少 `患者id`，代码会报错，不会静默回退到 session 随机切分。
4. 类别变量编码改为 source-fitted mapping：在 Shenyi 拟合类别到整数的映射，再应用到 Fuding；Fuding-only 类别编码为 unknown。
5. `src/data_pipeline/HBD_data.py` 与 `src/data_pipeline/HBD_data_fuding.py` 的最终历史均值覆盖逻辑改为 prior-only：先写入既往均值，再把当前 session 纳入累计。

## 后续复跑前必须完成

1. 删除旧的 `data/processed/*_final_data.csv` 和中间缓存，重新生成最终 CSV。
2. 抽样审计历史特征：
   - 每名患者首次 session 的历史均值和历史率应为 0。
   - 第二次 session 只能使用第一次 session。
   - 当前 session 的 outcome 和 event time 不应进入自己的历史特征。
3. 审计预测时点：
   - 如果研究目标是透析开始前或早期预测，应移除所有治疗完成后才能知道的特征。
   - 重点检查 `透析中*_mean/std`、`动脉压_mean/std`、`透析液温度_mean/std` 等是否属于未来信息。
4. 重新生成 target split 审计表：
   - adaptation/validation/test 的 patient 数、session 数、event 数。
   - 三个集合之间 patient id 交集必须为 0。
5. 保存每次复跑的配置、git hash、数据文件 hash 和环境快照。

## 推荐模型比较

主表至少包括：

1. Penalized Cox 或 CoxPH。
2. LightGBM/Cox surrogate 或其他强传统基线。
3. Source-only deep survival。
4. Source-pretrained + target fine-tune。
5. CDAN-GSN full model。

消融建议：

1. No adversarial loss。
2. No gated mask。
3. No KAN tokenizer。
4. No historical features。

## 需要删除或重做的旧结果

以下旧结果不能直接进入投稿稿件：

1. `tables/table3_pvalues.*`：当前 p-value 生成逻辑是占位，不是真实统计检验。
2. `tables/table4_fairness.*`：当前 subgroup C-index 来自模拟预测，不是真实模型输出。
3. `tables/table2_performance.*` 中 AUC 为 0.000 的列：这表示指标未有效计算，不应作为结果报告。
4. 归档 runs 中 C-index 约 0.93 的结果：除非能用 patient-level split、prior-only 历史特征和真实预测文件复现，否则不应作为主结果。

## 文稿表述边界

建议使用：

- target-center updating
- locally updated survival model
- transport-aware prediction
- held-out target-center patients
- residual calibration error

避免使用：

- unsupervised domain adaptation
- no target labels
- causal-aware
- causal consistency
- fairness analysis，除非用真实预测重算亚组性能并报告不确定性

## 投稿定位

完成上述整改并复跑后，优先考虑 Clinical Kidney Journal、Kidney Medicine、BMC Nephrology 或 Scientific Reports。若 patient-level held-out 结果稳定，校准和 DCA 可信，并有完整强基线与消融，再考虑更高层级的肾脏病或医学信息学期刊。
