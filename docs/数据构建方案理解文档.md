# 血液透析数据构建方案 — 完整理解文档

> **Note**: Raw data (`updated_dataset_*.csv`) and intermediate processing files (`*_optimized_data*.csv`, `*_result_df*.csv`, `removed_inconsistent_rows.csv`) have been moved to `archive/data_backup_20260627/` for storage optimization. The current project only uses the final processed files: `深医_final_data.csv` and `福鼎_final_data.csv`. To re-run the data pipeline, restore raw data to `data/raw/` directory.

## 一、总体架构

```
原始CSV (updated_dataset_shenyi.csv / updated_dataset_fuding.csv)
    │
    ▼
Phase 1: 基础特征工程 (shengyi_dataset / fuding_dataset)
    │  ├─ 列表字段解析 (透中血压、脉搏、超滤率等)
    │  ├─ 极值处理 (5%-95%分位数截断)
    │  ├─ 衍生特征 (透析年龄、瘘管使用时间、高血压诊断等)
    │  ├─ 事件标记 (透中低血压/高血压计算、阶段标签)
    │  ├─ 新增临床特征 (脉压差、平均动脉压、超负荷、超滤率_绝对、透析龄占比)
    │  └─ 输出: 深医/福鼎_optimized_data透前动脉压.csv
    │
    ▼
Phase 2: 历史平均值计算 (process_historical_averages)
    │  ├─ 按患者分组，计算每个指标的历史均值 (cumulative expanding mean)
    │  ├─ 30个线程并行处理 (按患者拆分)
    │  ├─ 输出: 深医/福鼎_result_df透前动脉压.csv
    │  └─ 与 optimized_data merge → whole_data
    │
    ▼
Phase 3: 历史比率计算 (process_historical_rates)
    │  ├─ 计算透中低血压历史发生率
    │  ├─ 计算降幅时间点区间历史分布 (4个区间)
    │  └─ 输出: Y_rate DataFrame (6列)
    │
    ▼
Phase 4: 最终合并
    │  ├─ whole_data + Y_rate → final_data
    │  └─ 输出: 深医/福鼎_final_data.csv
```

## 二、Phase 1 — 基础特征工程详解

### 2.1 数据源差异

| 维度 | 深医 (Shenyi) | 福鼎 (Fuding) |
|------|---------------|---------------|
| 透中血压格式 | 独立列: 透析中收缩压/舒张压 (JSON列表) | 单列: 透中血压 (字符串 "收缩压/舒张压,收缩压/舒张压,...") |
| 超滤量 | 列表格式, 取MAX | 单值 × 1000 (L→mL) |
| 透析液温度 | 39°C | 37°C |
| 时间格式 | `%Y-%m-%d %H:%M:%S` | 混合格式 (需多格式解析) |

### 2.2 列表字段处理

```python
list_columns = [
    "透析中收缩压", "透析中舒张压", "透析中脉搏",
    "超滤率", "超滤量", "静脉压", "原始动脉压",
    "血流速", "透析液温度", "跨膜压"
]
# 深医: JSON字符串 → ast.literal_eval → float list
# 福鼎: 字符串 → str.strip("[]").str.split(",") → float list
```

每个列表字段计算 `_mean` 和 `_std` 作为静态特征。

### 2.3 事件标记逻辑

**透中低血压判定** (`calculate_pressure_change`):
- 基准: 透前收缩压
- 阈值: 收缩压下降 ≥ 30 mmHg 或 收缩压 < 90 mmHg

**阶段标签** (基于事件发生时间 `et_min`):
- `stage_30_60_120`: 事件在30min内=1, 60min内=2, 120min内=3, 之后=3
- `stage_30_90_120`: 同上，边界改为30/90/120

### 2.4 新增临床特征

| 特征 | 公式 | 临床意义 | clip范围 |
|------|------|---------|----------|
| 脉压差 | 透前收缩压 - 透前舒张压 | 血管弹性指标 | 无 |
| 平均动脉压 | 1/3×收缩压 + 2/3×舒张压 | 组织灌注压 | 无 |
| 超负荷 | (透前体重 - 干体重) / 干体重 | 容量状态 | [-0.1, 0.3] |
| 超滤率_绝对 | 超滤量MAX / 实际透析时长 | 脱水速率 (mL/h) | [0, 3000] |
| 透析龄占比 | 透析龄 / 透析年龄 | 透析经验相对值 | [0, 1] |

### 2.5 关键问题: 超滤量MAX

- **深医**: 超滤量是列表, 取 `np.max(lst)`, 原始单位 mL
- **福鼎**: 超滤量是单值, `超滤量 × 1000` (L→mL)
- 两者单位统一为 mL 后, 用 99% 分位数截断异常值
- 深医截断值: 4100 mL, 福鼎截断值: 4000 mL

## 三、Phase 2 — 历史平均值计算

### 3.1 设计逻辑

对每个患者, 按透析日期排序, 计算每个指标的**历史累计均值**:

```
第n次透析的"历史平均X" = mean(X_1, X_2, ..., X_{n-1})
第1次透析的"历史平均X" = 0
```

### 3.2 mean_columns (30列)

```
透前体重, 透前呼吸频率, 透前体温, 干体重, 透析液钙浓度, 透析液电导率,
实际透析时长, 透前收缩压, 透前舒张压,
涨幅时间点比值区间, 涨幅时间点差值区间,
降幅时间点比值区间, 降幅时间点差值区间,
降幅时间点比值, 降幅时间点差值, 涨幅时间点比值, 涨幅时间点差值,
透中高血压_计算, 透中低血压_计算, 透前体重-干体重,
透析中收缩压_mean, 透析中舒张压_mean, 透析中脉搏_mean,
超滤率_mean, 静脉压_mean, 动脉压_mean, 血流速_mean,
透析液温度_mean, 跨膜压_mean,
透前动脉压, 透后动脉压, 超滤量MAX,
脉压差, 平均动脉压, 超负荷, 超滤率_绝对, 透析龄占比
```

### 3.3 并行架构

```
按患者分组 (深医: 1637患者, 福鼎: ~500患者)
    ↓
ThreadPoolExecutor (30线程)
    ↓
每个线程处理一个患者的所有透析记录
    ↓
pd.concat 合并所有结果
    ↓

```

### 3.4 缓存机制

### 4.1 计算逻辑

对每个患者, 按透析日期顺序遍历:

```python
# 6个比率指标:
```

## 六、当前存在的问题

### 6.1 超滤率_绝对 clip 范围错误 (已修复)
- 原问题: `超滤比 = 超滤量MAX / 实际透析时长`, 单位 mL/h (~500-700)
- 原 clip: `clip(0, 20)` → 100% 数据被截断到 20
- 修复: 重命名为 `超滤率_绝对`, clip 改为 `(0, 3000)`

### 6.2 历史平均值计算的 pandas 索引冲突
- `merge` 后 DataFrame 索引可能重复
- `groupby().cumsum() / count()` 触发 `cannot reindex on an axis with duplicate labels`
- `expanding().mean()` 触发 `Columns must be same length as key`
- 根因: merge 后索引与 groupby 内部索引不一致

### 6.3 历史比率计算逻辑不一致
- 并行版本和串行版本输出列名不同
- 串行版本中 `history_HBP` 在低血压=0时被重置为0, 逻辑有误

### 6.4 缓存文件导致旧数据被复用
- `optimized_data透前动脉压.csv` 包含旧的 `超滤比` 列
- 新代码使用 `超滤率_绝对`, 但缓存文件未更新
- 需要删除所有缓存文件强制重新生成

## 七、修复方案

### 7.1 历史平均值计算修复

使用 numpy 手动实现 expanding mean, 绕过 pandas 索引问题:

```python
for col in mean_columns:
    result = np.zeros(len(whole_data))
    for pid, group in whole_data.groupby('患者id', sort=False):
        indices = group.index.values
        values = whole_data.loc[indices, col].values
        cumsum = np.nancumsum(values)
        counts = np.arange(1, len(values) + 1)
        result[indices] = cumsum / counts
    whole_data['历史平均' + col] = result
```
