# 生存与域适应研究方案

## 设计目标

研究两个允许共存的透析中终点：IDH 与 IH。目标不是证明复杂模型天然优越，而是检验在固定 Fuding 测试患者上：目标中心标注更新是否改善跨中心预测，以及 CDAN 是否在普通目标更新之外提供可重复的增量。

IDH 定义为透前 SBP 与任一透中 SBP 差值至少 30 mmHg，或任一透中 SBP 不高于 90 mmHg。IH 定义为任一透中 MAP 较透前 MAP 上升超过 10 mmHg。

## 五级证据链

1. **校准双终点基线**：分别比较 source logistic、local logistic、source MLP 与普通 target-updated MLP。source 模型只用 source validation 校准；local/updated 模型只用 target validation 校准。
2. **固定拆分多种子**：`split_seed` 始终不变，仅循环 `initialization_seeds`。所有 run 必须具有完全相同的 target test 患者，否则聚合直接失败。
3. **时间测量机制审计**：比较两中心测量间隔、事件时间高频节点，以及事件落在 60/120/180/240 分钟的集中度。集中度差异超过 0.20 时，Cox 自动降级为敏感性分析。
4. **离散时间模型**：按共同 60 分钟区间建立 person-period 数据。非事件随访使用 `duration_minutes`；事件使用首次检出时间。报告 60、120、180、240 分钟累计风险。
5. **CDAN 增量消融**：从同一个 source 离散时间模型复制两份相同初始权重。普通分支只做 target update；CDAN 分支额外加入以预测风险为条件的域分类损失。唯一方法效应是 `CDAN - plain target update`。

## Cox 与 CDAN 的定位

Cox 使用事件时间；未发生事件时使用透析结束时长作为删失时间。由于两中心事件时间受测量网格影响，Cox 结果只有在时间审计通过时才可升级为主要证据，否则只能报告为敏感性分析。

CDAN 应用于离散时间 hazard，而不是在 mini-batch 中近似 Cox 风险集。这样避免不完整风险集造成的 Cox 偏似然错误，同时允许对共同时间区间的风险表示做条件域对齐。

可投稿的方法创新表述必须是条件式的：双终点、患者隔离的跨中心离散时间风险建模，以及 CDAN 相对普通目标中心更新的增量检验。不能仅因使用了 Cox/CDAN 名称就宣称创新有效。

## 结论门槛

- 普通更新相对 zero-shot 的提升需在固定测试患者和多个初始化种子下方向一致。
- CDAN 必须相对普通更新在预设时间窗获得正向患者 bootstrap 差值，并在多种子下稳定；否则结论是“未检测到域对齐增益”。
- CDAN 与 local baseline 接近时，不能写“优于本地模型”。
- 时间审计失败时，不得用 Cox 结果支撑精确事件时间或比例风险主张。
- IDH 与 IH 分别报告，不做互斥竞争风险解释，因为同一次会话可以同时发生。

## 一键入口

```bash
python run_pipeline.py /path/updated_dataset_shenyi.csv /path/updated_dataset_fuding.csv
```

输出位于独立的 `experiments/pipeline_runs/pipeline_<UTC时间>/`，包括构建审计、五个固定种子的校准二分类结果、时间机制审计、离散时间逐例预测、Cox 敏感性结果、CDAN 增量结果、模型 checkpoint 和每一步日志。任一步失败即停止，已完成的 partial JSON 和 checkpoint 保留。
